# Alive logo and icons

The Alive logo is the artwork Rohan supplied on 4 November 2026: a
gradient letter A in purple and blue, an orbit ring, and a lightning
bolt, with the word Alive beneath it. The full logo with the wordmark
lives in the app at `src/assets/alive-logo.png` and is shown on the
About page.

The application icon uses the symbol part of that same logo without the
wordmark, because the word cannot be read at tray and taskbar sizes. The
symbol sits on the dark background of the original artwork, finished as
a rounded square in the Windows 11 style. The packaged set in this
folder is:

- `icon.png` at 512 pixels, used by the bundle and the tray
- `icon.ico` with 16, 24, 32, 48, 64, 128 and 256 pixel sizes
- `32x32.png`, `128x128.png` and `128x128@2x.png`

Earlier marks kept for reference only: `icon.svg` was the first basic
mark, and an Unsplash heartbeat photograph by Joshua Chehov was used
briefly on the same day before Rohan supplied this logo.
